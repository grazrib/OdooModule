Overview
------------------------------------------------------
**Advanced Label Studio / Builder** is a powerful and intuitive module that transforms how you design and print professional labels inside Odoo.

From barcode sheets to product stickers — it delivers pixel-perfect accuracy, modern design control, and seamless Odoo integration.

Built with flexibility and precision in mind, it lets you create custom label layouts visually, link product data fields dynamically, and print perfectly aligned labels every time.

------------------------------------------------------
Highlighted Features
------------------------------------------------------

✅ **Millimeter Precision**
Design labels that print exactly as previewed — no misalignment or scaling issues.

✅ **Multi-Element Editor**
Add text, barcode, image, and shape elements — each with independent X/Y position, size, and rotation control.

✅ **Dynamic Field Binding**
Link product data fields like Name, SKU, Price, or Barcode dynamically from Odoo.

✅ **Predefined Templates**
Instantly use built-in templates like **Dymo 1x1**, **A4 2x7**, and **A4 4x7**, or create your own layouts.

✅ **Advanced Print Wizard**
Select paper format, quantity, and even define the **starting label position** for partially used sheets.

✅ **Paperformat Sync**
Automatically adjusts margins and alignment according to the selected paper format in Odoo.

✅ **Live Preview**
Real-time label rendering — see design changes instantly without reloading.

✅ **100% Odoo Native**
Runs fully inside Odoo — no external dependencies, plug-ins, or scripts required.

Dependencies
============
This module requires the Cairo graphics library for image and barcode rendering.

**To install manually (Ubuntu / Debian):**

.. code-block:: bash

   sudo apt install libcairo2 libcairo2-dev pkg-config
   pip install rlPyCairo reportlab pillow pycairo
