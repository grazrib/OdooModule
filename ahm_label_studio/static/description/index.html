Overview

Product Label Studio PRO is a complete Label Builder for Odoo that allows you to design, preview, and print product labels, barcode labels, DataMatrix labels, and Dymo stickers. Featuring a modern drag-and-drop Dynamic Label Studio, it gives you full control over millimeter-perfect product labeling inside Odoo.

Fully integrated with Inventory, Product, Barcode, and Sales modules.

Key Features

Everything you need to design and print professional product labels inside Odoo.

Millimeter-Perfect Accuracy

Print labels exactly as designed - no scaling or alignment issues.

Drag-and-Drop Dynamic Editor

Add text, barcode, images, lines, and shapes with exact XY positioning.

Dynamic Field Binding

Auto-link name, SKU, barcode, price, and custom fields directly from Odoo.

Predefined Templates

Dymo 1x1, A4 2x7, A4 4x7, image and barcode layouts and more.

Advanced Print Wizard

Choose quantity, paper format, and starting label position for partial sheets.

Paperformat Sync

Auto-syncs with Odoo paper formats ensuring perfect margins.

Live Preview

See changes instantly without exporting or refreshing.

100 Percent Native to Odoo

No external apps - everything runs inside Odoo.

Extra Features (Enhanced Version)

  • Sequence-based layering (Z-order): background elements under foreground fields.
  • Background support via image or full-width line bands.
  • Variable fields: today’s date and current date-time.
  • Currency formatting: symbol before/after and per-line decimal precision.
  • Default barcode type at template level + auto-sync to lines.
  • Per-line toggle for human-readable barcode text.
  • Template Export/Import as JSON for migration and reuse.
  • Demo templates protected from overwrite on module upgrades.
  • New included template: A4 3x8 (64x34).

Dependencies

This module requires the Cairo graphics library for image and barcode rendering.

To install manually (Ubuntu / Debian): 
sudo apt install libcairo2 libcairo2-dev pkg-config
pip install cairo reportlab pillow

Funzionalità Extra (Versione Potenziata) – Italiano

Questa versione contiene miglioramenti sviluppati per un utilizzo professionale in azienda.

  • Stratificazione tramite sequence: gli elementi con sequence più bassa restano sotto.
